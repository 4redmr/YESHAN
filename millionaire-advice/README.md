# 억만장자의 아침 서신 (The Chairman's Morning Letter)

매일 **오전 7시**, 그리고 **컴퓨터를 켜고 로그인할 때마다** 억만장자 말투의 조언 창이 자동으로 뜹니다.

- Chapter Ⅰ — 클로드 코드 초보를 위한 사용법 조언 (공백 제외 4,000자 이상)
- Chapter Ⅱ — 삶과 방향에 대한 조언 (공백 제외 3,000자 이상)
- 매일 바뀌는 "오늘의 한 줄"
- 블랙 & 골드 디자인, 시스템이 라이트 모드면 아이보리 & 골드로 바뀝니다

## 설치

먼저 이 `millionaire-advice` 폴더를 컴퓨터의 **바뀌지 않을 위치**(예: `문서\millionaire-advice`)에 두세요. 설치 후 폴더를 옮기면 다시 설치해야 합니다.

### Windows
1. `install-windows.bat` 을 더블클릭합니다. (관리자 권한 필요 없음)
2. 끝나면 서신이 한 번 바로 열립니다. 이후로는 매일 07:00과 로그인할 때마다 자동으로 열립니다.
   - 7시에 컴퓨터가 꺼져 있었다면 다음에 켰을 때 열립니다.
   - Edge(또는 Chrome)의 앱 모드로 열려 주소창 없는 깔끔한 창으로 보입니다.
3. 제거: `uninstall-windows.bat` 더블클릭.

### macOS
```bash
bash install-mac.sh            # 설치
bash install-mac.sh --uninstall  # 제거
```

## 내용 바꾸기
`index.html` 안의 글을 그대로 고치면 됩니다. 클로드 코드에게 "index.html의 Chapter Ⅱ를 이번 달 내 노션 기록 기준으로 새로 써 줘"라고 맡겨도 됩니다.
