# 광고성 리뷰 필터링 기준 (초안)

지역 맛집 신뢰도 앱의 신뢰도 점수에 들어가는 신호 중 하나로, 리뷰 텍스트가 광고·협찬성인지 판별하기 위한 기준을 정리한다. 이 문서는 초안이며, 실제 데이터로 임계값을 검증하기 전까지는 참고용이다.

## 1. 목적

- 앱이 보여주는 리뷰·평점에서 광고·협찬성 리뷰의 영향을 줄여 신뢰도 점수를 더 정확하게 만든다.
- 리뷰를 "삭제"하거나 "가짜"로 단정하지 않고, 신뢰도 점수에 반영할 "광고 의심도"를 매긴다. 오탐이 있을 수 있으므로 사용자에게는 단정적 표현을 쓰지 않는다.

## 2. 광고·협찬성 리뷰의 텍스트 패턴

### 2.1 명시적 키워드
리뷰 본문에 아래 유형의 표현이 있으면 협찬/체험단임을 사실상 공개한 경우다.
- 협찬, 체험단, 원고료, 제공받았습니다, 제공받은, 서비스로 받음, 무료로 제공, 업체로부터 제공
- 해시태그 형태: `#협찬`, `#체험단`, `#광고`, `#유료광고`

### 2.2 과장된 감탄사·반복 표현
- "인생맛집", "레전드", "미쳤다", "꿀맛", "존맛", "최고예요" 등 감탄사가 리뷰 전체에서 비정상적으로 높은 비율을 차지
- 같은 감탄사·이모지가 여러 문장에서 반복
- 느낌표·이모지 밀도가 비정상적으로 높음 (예: 문장당 평균 2개 이상)

### 2.3 정형화된 문단 구조
체험단 리뷰 특유의 고정 순서가 반복되는 경우:
1. 업체 소개(위치, 주차 안내)
2. 메뉴/가격 나열
3. 사진 다수 삽입
4. "다음에 또 가고 싶다"류의 마무리 문장

이 순서가 같은 작성자의 여러 리뷰에서, 또는 같은 가게에 달린 여러 리뷰에서 거의 동일하게 반복되면 템플릿화된 리뷰로 의심한다.

### 2.4 유사 문구 반복 (복붙 패턴)
- 같은 가게에 달린 여러 리뷰 간 문장 유사도가 비정상적으로 높음 (표절·복붙 의심)
- 한 작성자가 짧은 기간에 작성한 여러 리뷰가 서로 비슷한 문장 구조를 가짐

### 2.5 업로드 패턴
- 특정 가게에 짧은 기간(예: 1~2주) 안에 비슷한 톤의 리뷰가 몰림
- 리뷰 작성 계정이 가입 직후 짧은 기간에 여러 업체 리뷰를 한꺼번에 작성
- 리뷰 작성자가 유독 한 업종(예: 특정 상권의 식당들)에만 집중되어 있음

## 3. 판별 규칙 초안 (룰 기반 점수화)

각 리뷰에 아래 규칙별 가중치를 더해 "광고 의심 점수"를 계산한다. 점수가 높을수록 신뢰도 점수에서 해당 리뷰의 영향력을 낮춘다.

| 규칙 | 조건 | 가중치(예시) |
|---|---|---|
| R1. 명시적 키워드 | 2.1의 키워드/해시태그 포함 | +40 (거의 확정) |
| R2. 감탄사 밀도 | 과장 감탄사 비율이 전체 문장의 30% 이상 | +15 |
| R3. 느낌표·이모지 밀도 | 문장당 평균 2개 이상 | +10 |
| R4. 정형화된 구조 | 2.3의 순서가 그대로 나타남 | +15 |
| R5. 문구 유사도 | 같은 가게의 다른 리뷰와 유사도 80% 이상 (예: 자카드 유사도 또는 임베딩 코사인 유사도) | +20 |
| R6. 업로드 패턴 | 동일 업체에 짧은 기간 내 유사 리뷰 급증, 또는 계정이 가입 직후 몰아서 작성 | +15 |

- **합산 점수 ≥ 50** → "광고 의심" 플래그. 신뢰도 점수 계산에서 가중치를 낮추거나 별도 표시.
- **합산 점수 30~49** → "협찬 가능성 있음"으로 약하게 반영 (가중치 소폭 축소만).
- **합산 점수 < 30** → 일반 리뷰로 간주.

임계값(50, 30 등)은 임시값이며, 실제 리뷰 샘플로 검증 후 조정이 필요하다.

## 4. 예시

**광고 의심 (R1+R2+R4, 점수 70):**
> "oo병원 근처 맛집 체험단으로 다녀왔어요! 인생맛집 레전드 미쳤다ㅠㅠ 주차는 건물 뒤편에 가능하고 메뉴는 1번2번3번... 다음에 또 방문하고 싶어요!"

**협찬 가능성 있음 (R2+R3, 점수 25 → 임계값 미달이지만 근접하므로 모니터링):**
> "여기 진짜 최고예요!! 완전 꿀맛!! 분위기도 좋고 직원분도 친절해요!! 또 올게요!!"

**일반 리뷰 (점수 0):**
> "점심에 가봤는데 국물이 좀 짰어요. 양은 많은 편. 평일 12시쯤 가면 자리 기다릴 수도 있어요."

## 5. 주의사항

- 공식 API로 받은 리뷰 데이터만 사용하고, 각 플랫폼의 크롤링·이용약관을 확인한다.
- 이 점수는 "가짜 리뷰 판정"이 아니라 신뢰도 점수에 들어가는 보조 신호다. 사용자에게 노출할 때도 "광고"라고 단정하지 않고 "협찬/광고성 표현이 포함될 수 있음" 정도의 참고 표시로만 쓴다.
- 오탐 사례(실제로는 일반 리뷰인데 감탄사가 많은 경우 등)를 수집해 규칙과 가중치를 주기적으로 조정해야 한다.
- 다음 단계: 실제 리뷰 샘플을 모아 R1~R6 각각의 정탐/오탐률을 확인하고 가중치를 재조정한다.
