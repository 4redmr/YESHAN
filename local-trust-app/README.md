# 지역 맛집 신뢰도 앱 — 프로토타입 (2단계)

데이터 소스 역할 분리(기본정보=카카오, 평점·리뷰=구글)의 배경은
[data-source-design.md](data-source-design.md) 참고.

광고성 리뷰와 앱마다 다른 별점 때문에 믿기 어려운 맛집 정보를, 공식 API 데이터만으로
신뢰도 신호로 바꿔 보여주는 작은 프로토타입이다.

## 왜 "앱 간 평점 괴리" 대신 "평점 vs 리뷰 수 괴리"로 시작하는가

원래 아이디어는 네이버 지도와 구글의 평점을 비교해 괴리가 큰 가게를 광고 의심으로
표시하는 것이었다. 하지만 확인해 보니:

- **구글 Places API**는 `rating`, `userRatingCount`를 공식으로 제공한다.
- **네이버 지역 검색 API**(공식, developers.naver.com)는 `title`/`category`/
  `address`/`roadAddress`/`mapx`/`mapy` 등만 주고 **평점 필드가 없다.** 네이버가
  2026년 6월부터 플레이스 페이지에 누적 별점을 노출하는 정책을 바꾸고 있지만, 이건
  웹 화면 표시 정책이고 API 제공과는 별개다. 화면을 크롤링해서 별점을 가져오는 건
  약관 위반 소지가 있어 이 프로젝트에서는 하지 않는다.

그래서 1단계는 **구글 Places API 하나만** 공식 데이터로 쓴다. "평점은 높은데 리뷰
수가 비정상적으로 적은" 가게를 광고 의심 신호로 본다 (광고로 단기간에 평점을 끌어올린
가게는 보통 리뷰가 많이 쌓이기 전이다). 네이버가 평점을 공식 API로 열어주면, 그때
"앱 간 괴리" 비교를 추가한다.

## 사용법

### 평점·리뷰 (구글 Places)

1. 구글 Cloud 프로젝트에서 Places API (New)를 켜고 API 키를 발급받는다.
2. 환경 변수로 키를 넣는다 (커밋하지 말 것):
   ```bash
   export GOOGLE_PLACES_API_KEY="여기에_키"
   ```
3. 확인할 가게 목록을 한 줄에 하나씩, `이름 주소` 형식으로 텍스트 파일에 적는다.
   `stores.sample.txt`를 참고.
4. 실행:
   ```bash
   python3 trust_score.py stores.sample.txt
   ```
   평점/리뷰수 판정과 함께, 리뷰 텍스트 중 광고 의심 문구가 있으면 `ad_filter.py`
   규칙(R1~R3)에 걸린 리뷰를 밑에 같이 보여준다.

### 기본정보 (카카오 로컬 API)

1. 카카오 디벨로퍼스에서 앱을 만들고 REST API 키를 발급받는다.
2. 환경 변수로 키를 넣는다 (커밋하지 말 것):
   ```bash
   export KAKAO_REST_API_KEY="여기에_키"
   ```
3. 같은 형식의 가게 목록 파일로 실행:
   ```bash
   python3 kakao_basic_info.py stores.sample.txt
   ```
   이름/카테고리/전화번호/주소만 나온다 — 평점·리뷰는 카카오에 없으므로 여기선 안 보여준다.

## 판정 기준 (지금은 아주 단순함)

- 평점 ≥ 4.7 인데 리뷰 수 < 30 → **광고 의심**
- 그 외 평점/리뷰 수가 있으면 → **정상**
- 구글에 평점·리뷰 수가 없으면 → **데이터 부족**
- 리뷰 텍스트 광고 의심 점수 ≥ 50 → **광고 의심**, 30~49 → **협찬 가능성 있음**
  (자세한 규칙은 `ad-review-filter.md`)

기준값(4.7, 30, 50, 30)은 모두 하드코딩된 추정치다. 실제 샘플로 돌려보고 조정이 필요하다.

## 다음 단계 (구현 계획)

1. 이 스크립트들로 실제 가게 10~20곳을 돌려보고 기준값이 말이 되는지 확인한다.
2. `ad_filter.py`는 R1~R3(키워드/과장 감탄사/느낌표 밀도)만 구현했다. R4~R6(정형화된
   구조/문구 유사도/업로드 패턴)은 리뷰·작성자 이력이 쌓여야 계산할 수 있어 보류.
3. 네이버 쪽에서 평점을 공식으로 받을 수 있는 경로가 생기면(네이버 지도 API, 사업주 공개
   데이터 등) 구글과 비교하는 "앱 간 괴리" 로직을 추가한다.
4. 가게 목록을 수동 텍스트 파일 대신 CSV나 작은 DB로 바꾸고, 카카오 기본정보와 구글
   신뢰도 신호를 하나의 결과로 합쳐 웹에서 보여주는 화면을 붙인다.
