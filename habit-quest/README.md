# 하루 퀘스트 (Haru Quest)

할 일을 체크하면 **언제 했는지**가 쌓이고, 앱이 그 기록으로 "나는 대략 몇 시에 이걸 한다"를 계산해서 그 시간에 알려 주는 습관 앱의 시험판입니다. 체크할 때마다 XP가 쌓이고, 어느 정도 습관이 되면 "이것들을 한 세트로 묶을까요?" 하고 물어봅니다.

- `index.html` 하나로 돌아갑니다. 설치, 서버, 빌드 없음.
- 처음 열면 **6주치 예시 기록**이 들어 있어서 시간 학습, 알람, 세트 제안을 바로 볼 수 있어요. "예시 지우고 내 퀘스트로 시작"을 누르면 비워집니다.
- 기록은 그 브라우저(localStorage)에만 저장됩니다. 다른 기기로 옮길 때는 설정의 **백업**을 쓰세요.

## 써 보는 법

웹 주소: **https://4redmr.github.io/YESHAN/** (GitHub Pages)

### 홈 화면에 앱처럼 깔기
- **아이폰**: Safari로 위 주소를 열고 → 아래쪽 공유 버튼(네모에 위쪽 화살표) → "홈 화면에 추가".
- **안드로이드**: 크롬으로 열면 앱 화면에 "홈 화면에 추가" 버튼이 나와요. 안 보이면 크롬 메뉴(⋮) → "홈 화면에 추가" 또는 "앱 설치".
- **PC**: 크롬/엣지 주소창 오른쪽의 설치 아이콘을 누르세요.

깔고 나면 주소창 없이 열리고, 인터넷이 없어도 열려요. 휴대폰 알림을 받으려면 앱 안의 "알람과 설정"에서 알림을 허용하세요.

### 알아 둘 점
- **알람은 앱이 열려 있을 때 울려요.** 서버 없이 돌아가는 웹 앱이라서 그렇습니다. 앱을 닫아도 알람을 받으려면 설정 → "달력 파일 만들기"로 `.ics`를 만들어 휴대폰 달력에 넣으세요. 배운 시간이 요일별 반복 일정 + 알림으로 들어갑니다. 시간이 바뀌면 다시 내보내면 돼요.
- **기록은 여는 곳마다 따로 저장돼요.** 클로드 링크에서 쓰던 기록은 설정 → "백업 만들기"로 복사한 뒤, 새 주소의 "백업 불러오기"에 붙여 넣으면 옮겨져요.
- PC에서는 `index.html`을 더블클릭해서 열어도 됩니다(이때는 설치와 오프라인 기능은 빠져요).

### GitHub Pages 처음 켜기 (한 번만)
1. 저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 바꿉니다.
2. 이 폴더가 `main` 브랜치에 들어가면 `.github/workflows/habit-quest-pages.yml`이 `habit-quest/` 폴더만 올립니다. 저장소의 다른 폴더는 올라가지 않아요.
3. 파일을 고쳐서 `main`에 넣을 때마다 자동으로 다시 올라갑니다. `sw.js`의 `VERSION`을 올리면 이미 깔린 앱도 새 버전을 받아요.

## 지금 들어 있는 기능

| 아이디어 | 어떻게 만들었나 |
|---|---|
| 할 일을 목록으로 적기 | 퀘스트 관리에서 추가. 이모지, 요일, 처음 시간(선택)을 정합니다 |
| 체크하면 시간이 남음 | 체크 한 번 = 시각 기록. 늦게 체크했으면 시간을 눌러 "아까 했어요"로 실제 시간을 넣습니다 |
| 통계로 "평소 몇 시"를 계산 | 평균 대신 **중간값**을 써서 어쩌다 늦은 하루에 흔들리지 않게 했어요. "± N분"으로 얼마나 일정한지도 보여 줍니다 |
| 처음부터 직접 셋팅해도 됨 | 처음 시간을 넣으면 기록이 3번 쌓일 때까지 그 시간으로 알려 줍니다. "고정"을 켜면 계속 그 시간이고, 실제 기록이 20분 넘게 다르면 옮길지 물어봐요 |
| 요일마다 다른 날 | 평일과 주말 기록이 40분 넘게 차이 나면 자동으로 나눠 계산합니다. 특정 요일만 다르면 그 요일만 따로 봅니다 |
| 스케줄이 매일 다른 사람 | "몇 시"보다 "하루 첫 체크 뒤 몇 분"이 더 일정하면 그 방식으로 예측합니다. 늦게 일어난 날은 알람도 같이 늦어져요 |
| 특별한 날 | 오늘을 "다른 날(휴가·야근·아픈 날)"로 표시하면 평균에서 빠지고 알람도 쉽니다 |
| 그 시간이 되면 알람 | 기본은 **평소 시간보다 늦을 때만** 알려요(바로 알리는 방식도 고를 수 있음). 시간이 들쭉날쭉한 일은 알람을 쉽니다. 10분 미루기, 오늘은 쉬기 버튼 |
| 퀘스트와 성취감 | 체크 10 XP, 평소 시간에 맞추면 +5, 그날 다 하면 +30, 세트 완주 +20. 레벨과 칭호, 배지 10종 |
| 습관이 되면 세트로 묶기 | 최근 3주 동안 같은 순서로 30분 안에 이어서 한 날이 80% 넘으면 "한 세트로 묶을까요?"를 물어봅니다. 묶으면 첫 시간에 한 번만 알려요 |
| 습관 판정 | 21일 넘게, 최근 3주 80% 이상, 시간이 ±30분 안 → "습관 완성". 66일 진행 막대 |
| 끊겨도 괜찮게 | 연속 기록이 끊겨도 점수를 깎지 않아요. "최근 7일 중 며칠"로 보여 주고, 쉬었다 돌아오면 "다시 시작" 배지 |
| 홈 화면 앱 | 휴대폰·PC에 앱처럼 설치, 오프라인에서도 열림, 알림을 누르면 앱이 열림 |
| 누구나 | 직장인·학생·주부·취준생·신앙과 배움 묶음 예시. 하루 시작 시각(기본 04:00)을 바꿀 수 있어서 밤에 일하는 사람도 맞출 수 있어요 |

## 계산 방식 (요약)

1. 퀘스트마다 최근 60일 기록을 모읍니다. 오늘과 "다른 날"은 뺍니다.
2. 오늘과 비슷한 날만 고릅니다: 전체 → (차이가 크면) 평일/주말 → (차이가 크면) 같은 요일.
3. 고른 기록의 중간값이 예상 시간, 중간값에서 떨어진 정도의 중간값이 "± 분"입니다.
4. "하루 첫 체크 뒤 몇 분"의 흩어짐이 시계 시간보다 40% 넘게 작으면 그쪽으로 예측합니다.
5. 흩어짐이 ±45분(설정 가능)보다 크면 예측은 보여 주되 알람은 걸지 않습니다.

## 다음 단계 아이디어 (아직 안 만든 것)

**바로 해 볼 만한 것**
- 주간 돌아보기 카드: "이번 주 가장 꾸준했던 일", "가장 자주 미룬 일"
- 퀘스트 순서 바꾸기, 세트 안 단계 순서 바꾸기
- 노션 연동: 하루 기록을 노션의 오늘의 동행 기록과 맞춰 보기

**진짜 앱으로 갈 때**
- 화면을 닫아도 울리는 알람: 휴대폰 앱(안드로이드/아이폰)의 예약 알림, 잠금화면 위젯에서 한 번에 체크
- 상황 신호로 알람: 회사 와이파이에 연결되면, 집에 도착하면, 알람 시계를 끄면 "하루 첫 체크"로 자동 기록
- 기기 간 동기화와 로그인
- 가족/친구와 함께하는 퀘스트, 서로 응원
- AI 코치: 기록을 보고 "수요일마다 영어를 빼먹어요. 시간을 옮겨 볼까요?" 같은 제안
- 세트가 커지면 "아침 루틴 20분" 타이머 모드

**사업으로 볼 때 생각할 점**
- 비슷한 앱: 습관을 게임처럼 만드는 앱, 루틴을 묶어 순서대로 해 주는 앱, 빈 시간에 습관을 넣어 주는 일정 앱은 이미 있어요. 이 앱의 차별점은 **사용자가 정하지 않아도 기록에서 시간을 배우고, 습관이 되면 먼저 묶자고 제안하는 것**입니다.
- 대상은 누구나 쓸 수 있지만, 처음 알릴 때는 한 집단에 집중하는 게 좋아요(예: 취준생의 아침 루틴).
- 위험: 기록이 쌓이기 전엔 할 일이 없음(직접 셋팅과 예시 묶음으로 보완), 알람이 많으면 지움(늦을 때만, 일정한 일만), 체크를 잊으면 데이터가 틀어짐("아까 했어요"로 보완).
- 수익 모델 후보: 기본 무료 + 동기화·위젯·AI 코치 유료, 또는 회사·학교 단체용.
