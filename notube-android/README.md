# 노튜브 저금통 (Android)

유튜브는 참은 만큼만 볼 수 있는 앱.

## 규칙
- 유튜브를 안 본 10분마다 볼 수 있는 시간 +1분 (3시간↑ 1.5배, 12시간↑ 2배, 24시간↑ 3배)
- 유튜브를 1분 보면 −1분
- 지갑이 0분이 되면 재생을 멈추고 차단 화면을 띄운 뒤 홈으로 내보내요. 안드로이드 13 이하는 유튜브 종료까지. 5분·1분 남았을 때 알림.
- 0분에서 시작해요.
- 저금통: 지갑 시간을 넣어 두면 매일 자정 10% 이자 (자정~자정 꼬박 들어 있던 시간만). 깨면 전부 지갑으로.
- 유튜브를 1분 넘게 켜면 참기 기록(배수)이 처음부터. 1분 미만은 봐주지만 한 기록 안에서 합쳐 3분이 넘으면 끝.

## 나만의 규칙
요일·시간대별로 효과를 적용 (밤을 넘기는 시간대는 시작한 날의 요일 기준):
- 자유 시간: 봐도 안 줄고 참기 기록도 안 끊김
- 적립 쉬기: 안 봐도 안 쌓임 (배수 단계는 계속 올라감)
- 유튜브 금지: 지갑에 시간이 있어도 차단
- 2배 적립
규칙을 바꾸면 지금 진행 중인 기록부터 적용. '처음부터 다시 시작'해도 규칙은 유지.

## 악용 방지
- 비상 탈출권: 10분 열기, 빚 15분, 하루 1번·주 3번, 30초 숙려, 유튜브 금지 규칙 시간엔 불가(금지 규칙이 탈출권보다 우선)
- 규칙을 느슨하게 바꾸면 24시간 뒤 적용, 엄격하게는 즉시. 규칙마다 적용 시작/끝 시각을 기록해 거슬러 적용되지 않음
- 규칙 변경·탈출권·보호 꺼짐·활동은 지울 수 없는 기록으로 남음
- 권한을 꺼도 다시 켜면 그동안 사용 기록으로 소급 차감 (시스템 보관 기간 약 7일 내)
- 삭제 방지(기기 관리자, 제어 정책 없음), 구글 자동 백업
- '처음부터 다시 시작'해도 빚·탈출권 횟수·규칙은 넘겨받음
- 백업 파일: 서명(앱을 뜯어보면 위조 가능), 재설치 후 7일 안 복원용만, 백업 이후 사용 기록 재계산

## 대체 활동
기도·운동·말씀읽기·독서·공부 타이머. 10분마다 +1분, 하루 30분까지, 활동 중 유튜브를 보면 보너스 없음.

## 필요한 권한
- 사용 시간 접근 (PACKAGE_USAGE_STATS): 유튜브가 화면에 있는지 확인
- 다른 앱 위에 표시 (SYSTEM_ALERT_WINDOW): 차단 화면
- 알림 접근 (권장, NotificationListener): 유튜브 백그라운드 재생 감지. 알림 내용은 읽지 않음
- 알림 (선택): 남은 시간 경고

## 감지 못 하는 것
- 브라우저(크롬 등)로 보는 유튜브
- 백그라운드 재생은 '알림 접근'을 허용해야 감지

## 코드 구조
- `Engine.kt` — 사용 기록 이벤트 → 번 시간/본 시간 계산 (순수 로직, 테스트 있음)
- `Ledger.kt` — 상태, 적립 규칙, JSON 저장
- `GuardService.kt` — 실시간 감시(2~3초), 차단 화면, 알림, 부팅 시 재시작
- `Media.kt` — 알림 접근 권한으로 유튜브 재생 상태 확인·일시정지
- `Rules.kt` — 규칙 정의와 시간 계산 (테스트 있음)
- `RulesUi.kt` — 규칙 카드·편집 화면
- `GuardAdmin.kt` — 삭제 방지 (기기 관리자)
- `MoreUi.kt` — 탈출권, 대체 활동, 지키기(보호·백업), 일·주·월 통계 화면
- `Repo.kt` — 권한 확인, UsageStatsManager 조회, 저장소
- `SyncWorker.kt` — 15분 주기 안전장치 정산
- `NotubeWidget.kt` — 홈 화면 위젯
- `MainActivity.kt` — Compose 화면
